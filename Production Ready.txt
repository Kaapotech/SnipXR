RAPORT PRODUCTION READINESS — SnipXR
======================================
Ultima actualizare: Mai 2026

STARE CURENTA: Nu este production-ready inca.
Aplicatia functioneaza, dar are probleme de securitate si UX care trebuie rezolvate inainte de lansare publica.


======================================
CE FUNCTIONEAZA ACUM
======================================

- Autentificare email + parola (cu bcrypt, parola hashata corect)
- Autentificare GitHub OAuth
- Inregistrare cont nou
- Scurtare linkuri si redirect catre URL original
- Numarare click-uri (analytics de baza)
- Dashboard cu istoricul linkurilor utilizatorului (acces doar plan Pro)
- Stergere linkuri din dashboard (Server Action cu verificare ownership)
- Generator QR code (accesibil doar utilizatorilor logati)
- Deploy automat pe Vercel cu prisma generate
- Rate limiting cu Upstash Redis pe /api/shorten si /api/auth/register
- Analytics per link in dashboard: tara (cel mai frecvent), browser, dispozitiv
  (tara detectata automat din x-vercel-ip-country pe Vercel; Unknown pe localhost)
- Sistem de planuri Free / Pro (camp plan pe User, default "free")
- Pagina /plans cu comparatie Free vs Pro
- Buton Upgrade in Navbar (vizibil cand esti logat)
- Templates accesibil doar utilizatorilor Pro (redirect la /plans altfel)
- Dashboard accesibil doar utilizatorilor Pro (redirect la /plans altfel)
- Navbar cu lock icon si tooltip "Necesita plan Pro" pe Dashboard si Templates pentru useri free
- Click pe link locked in Navbar redirectioneaza la /plans
- Linkuri anonime claimed la login se numara in limita lunara de 15 (nu se poate ocoli limita)
- Mesaje de eroare corecte: 5 linkuri anonim, 15 linkuri/luna cont free, 5 QR/luna


======================================
PROBLEME CRITICE (rezolva inainte de lansare)
======================================

1. SECRETE EXPUSE
   - NEXTAUTH_SECRET este un string slab si a fost expus.
     Inlocuieste-l cu: openssl rand -base64 32
   - Credentialele GitHub OAuth si parola bazei de date au fost expuse in istoric.
     Regenereaza-le imediat din GitHub Developer Settings si Supabase Dashboard.

2. NEXTAUTH_URL in Vercel
   - Trebuie sa fie URL-ul exact al site-ului de productie (ex: https://snipxr.com)
   - Daca e gresit, sesiunile nu persista si utilizatorii sunt delogati la refresh.


======================================
PROBLEME MEDII (importante pentru UX)
======================================

3. LOGIN CU GOOGLE NON-FUNCTIONAL
   - GOOGLE_CLIENT_ID si GOOGLE_CLIENT_SECRET nu sunt configurate in Vercel.
   - Butonul Google apare, dar nu face nimic util.

4. FARA VERIFICARE EMAIL
   - Oricine poate crea cont cu orice adresa de email fara confirmare.
   - Risc de spam si conturi false.


======================================
FEATURES LIPSA (pentru versiunea completa)
======================================

- Custom aliases (ex: snipxr.com/oferta-mea)
- Verificare URL impotriva bazelor de date phishing (Google Safe Browsing API)
- Analytics detaliate per click (istoric complet, grafice, breakdown pe tari)
- Pagina de profil utilizator
